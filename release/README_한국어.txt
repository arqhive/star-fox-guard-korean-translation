스타폭스 가드 한글 패치 v0.9
================================

Wii U "스타폭스 가드" 일본판(WUP-P-BWFJ, 00050000101BEB00)의
비공식 한국어 팬 패치입니다. 대사는 일본어판 원문을 기준으로 번역했습니다.

제작: arqhive


1. 준비물
---------
- 본인이 소유한 게임에서 직접 덤프해 복호화한 일본판 데이터
  그중 content 폴더의 data000.cpk 파일 하나만 있으면 됩니다.

    파일명 : data000.cpk
    MD5    : 3ba7b1e862cfff770066b5792381c264
    크기   : 469,484,032 바이트

  ※ 북미판·유럽판에는 적용할 수 없습니다.
  ※ 이미 패치한 파일에 덧씌울 수 없습니다. 항상 원본에 적용하세요.

- Wii U 본체: Aroma 환경과 SDCafiine(콘텐츠 리디렉션) 기능
- SD 카드 여유 공간 약 600MB (FAT32)
- 윈도우 PC (패치를 만드는 용도, 별도 설치 필요 없음)


2. 패치 만들기
--------------
1) 이 압축 파일을 폴더째 풀어 주세요.
   (인터넷에서 받은 zip은 마우스 오른쪽 → 속성 → "차단 해제"를 먼저 체크하면
    스크립트가 막히지 않습니다.)

2) 원본 data000.cpk 파일을 "패치하기.bat" 아이콘 위로 끌어다 놓습니다.
   또는 "패치하기.bat"을 그냥 실행한 뒤 파일 경로를 입력해도 됩니다.

3) 1~2분 기다리면 out 폴더에 한글판 data000.cpk가 만들어집니다.
   원본 파일은 건드리지 않습니다.

   - 원본 확인 : 시작할 때 MD5로 판본을 검사합니다.
   - 결과 확인 : 완성된 파일이 제작자 빌드와 같은지 MD5로 검사합니다.

   SD 카드 경로까지 한 번에 복사하려면 명령 프롬프트에서 이렇게 실행하세요.

     패치하기.bat "D:\경로\data000.cpk" --sd E:


3. Wii U에 넣기
---------------
SD 카드에 아래 경로를 만들고 한글판 data000.cpk를 넣습니다.

  wiiu\sdcafiine\00050000101BEB00\KoreanTranslation\content\data000.cpk

Aroma를 켜고 SDCafiine(콘텐츠 리디렉션)을 활성화한 상태에서 게임을 실행하면
한글로 나옵니다. 원래대로 돌리려면 위 폴더를 지우거나 SDCafiine을 끄면 됩니다.


4. 패치 내용
------------
- 게임 내 일본어 텍스트 전체 한글화 (1,529문단, 메뉴·튜토리얼·스토리 대사·
  방해 통신·도움말·크레딧 등)
- 글자는 원본 UI 글꼴 모양에 맞춰 새로 그려 넣었습니다 (Noto Sans KR 기반)
- 그림 속 일본어 2장 한글화 (프롤로그 계약서, 크레딧 손글씨 서명)
- 인물·지명은 한국 정식 발매작(스타폭스 2026, 스타폭스 64 3D) 표기 기준
  — 폭스 맥클라우드, 팔코 람바디, 페피 헤어, 슬리피 토드, 안돌프, 코네리아

알려진 제한
- 음성은 일본어 그대로입니다.
- 프로필 심벌 아이콘의 한자(零·技·侍·秘·戦·忍)는 디자인 요소로 보고 남겼습니다.
- 온라인 기능은 서비스 종료로 확인하지 못했습니다.

이상한 화면이나 어색한 문장을 발견하면 알려 주세요.


5. 참고
-------
- 이 패치에는 게임 데이터가 들어 있지 않습니다. 한글 텍스트와 새로 그린
  글자 텍스처만 들어 있으며, 적용은 본인이 가진 원본 파일에 대해 이루어집니다.
- 패치 프로그램은 파이썬 스크립트(patcher\patch.py)와 python.org에서 배포하는
  임베더블 파이썬으로만 구성되어 있습니다. 내용을 직접 열어 확인할 수 있습니다.
