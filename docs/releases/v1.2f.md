완성판입니다. 대사를 다시 검수하고, 한글 글씨를 원본 게임 글씨와 어울리게 다듬었습니다.

**원본 일본판 `data000.cpk`에 적용하는 전체 패치입니다.** 이미 한글 패치한 파일에는 적용할 수 없습니다.

## 변경 사항

### 대사와 문장

- 62개 문단의 문장을 다듬었습니다. 빠진 조사와 뜻을 채우고, 원문에 맞게 말투를 고쳤습니다.
- 화면 폭 때문에 줄여 썼던 대사 6곳을 원래 문장으로 되살렸습니다.
- 대사에서 빠져 있던 마침표를 넣고, 문장이 끝났는데 쉼표로 이어 쓴 곳을 고쳤습니다.
- 표기를 통일했습니다. 라일라트계, 녀석·놈 구분, 대물 등입니다.

### 글씨

- 한글 외곽선을 원본 게임 글씨(느낌표 등)와 같은 두께로 맞추고, 가장자리를 깔끔하게 다듬었습니다.
- 글자 사이 간격을 고르게 맞췄습니다. 행성 이름·메뉴 제목·레어메탈처럼 글자가 붙어 보이던 곳은 간격을 넓혔습니다.
- 대사 글씨는 원본처럼 가늘게, 제목 글씨는 원본처럼 굵게, 구간마다 굵기를 원본에 맞췄습니다.
- '방어 성공!', '적 접근!', 행성 이름 같은 큰 글씨에서 획 사이가 메워져 뭉개지던 문제를 고쳤습니다.
- 이름표 '슬리피'처럼 자음과 모음이 붙어 보이던 문제를 고쳤습니다.

## 적용 방법

1. `BWFJ_KPatch_v1.2f.zip`을 폴더째 풀고, 본인이 덤프해 복호화한 일본판 원본 `content/data000.cpk`를 `패치하기.bat`에 끌어다 놓습니다.
2. `out` 폴더에 만들어진 `data000.cpk`를 SD 카드의 `wiiu\sdcafiine\00050000101BEB00\KoreanTranslation\content\data000.cpk`에 넣고, Aroma에서 SDCafiine을 켠 채 게임을 실행합니다.

자세한 방법은 동봉한 `README_한국어.txt`를 참고하세요.
