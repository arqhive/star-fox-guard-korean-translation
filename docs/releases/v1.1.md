계약서와 크레딧의 서명 그림을 개선한 업데이트입니다. 대사와 게임 안 폰트 데이터는 v1.0과 같습니다.

**원본 일본판 `data000.cpk`에 적용하는 전체 패치입니다.** 이미 한글 패치한 파일에는 적용할 수 없습니다.

## 변경 사항

- 계약서와 크레딧의 서명을 자연스러운 손글씨로 바꿨습니다.
- 계약서 서명의 획과 농도를 보강하고, 도장 주변에 남아 있던 기존 서명의 흔적을 정리했습니다.
- 계약서 제목·본문·테두리와 대사, 게임 안 폰트 데이터는 v1.0과 같습니다.
- 그림 준비 도구와 기존 한글 CPK의 그림만 갱신하는 도구, 작업 기록을 추가했습니다.

## 배포 파일

| 파일 | 입력 | 설명 |
|---|---|---|
| `StarFoxGuard_KO_v1.1.zip` | 원본 일본판 `data000.cpk` | 스크립트 패처, `패치하기.bat`, 임베더블 파이썬, 사용자 설명서. |

패처는 시작할 때 원본 MD5를, 끝날 때 결과 MD5를 검사합니다.

## 적용 방법

1. `StarFoxGuard_KO_v1.1.zip`을 폴더째 풀고, 본인이 덤프해 복호화한 일본판 원본 `content/data000.cpk`를 `패치하기.bat`에 끌어다 놓습니다.
2. `out` 폴더에 만들어진 `data000.cpk`의 확인값을 아래 표와 비교합니다.
3. 결과 파일을 SD 카드의 `wiiu\sdcafiine\00050000101BEB00\KoreanTranslation\content\data000.cpk`에 넣고, Aroma에서 SDCafiine을 켠 채 게임을 실행합니다.

자세한 방법은 동봉한 `README_한국어.txt`를 참고하세요.
