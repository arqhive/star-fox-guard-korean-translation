번역 전문을 다시 검수해 문구를 다듬은 정식 버전입니다.

**원본 일본판 `data000.cpk`에 적용하는 전체 패치입니다.** 이미 한글 패치한 파일에는 적용할 수 없습니다.

## 변경 사항

- 번역 전문을 다시 검수해 124개 문단의 문구를 다듬었습니다. 어색한 직역투, 대사 어조, 용어를 고쳤습니다.
- 검수로 길어져 화면 폭을 넘던 51줄을 다시 맞췄습니다. 칸이 좁아 검수 문구를 그대로 넣을 수 없는 11건은 뜻이 같은 짧은 표현으로 바꿨습니다.
- 적 로봇 이름 표기를 "코소로이드"로 통일했습니다(용어집 포함).

## 배포 파일

| 파일 | 입력 | 설명 |
|---|---|---|
| `StarFoxGuard_KO_v1.0.zip` | 원본 일본판 `data000.cpk` | 스크립트 패처, `패치하기.bat`, 임베더블 파이썬, 사용자 설명서. |

패처는 시작할 때 원본 MD5를, 끝날 때 결과 MD5를 검사합니다.

## 적용 방법

1. `StarFoxGuard_KO_v1.0.zip`을 폴더째 풀고, 본인이 덤프해 복호화한 일본판 원본 `content/data000.cpk`를 `패치하기.bat`에 끌어다 놓습니다.
2. `out` 폴더에 만들어진 `data000.cpk`의 확인값을 아래 표와 비교합니다.
3. 결과 파일을 SD 카드의 `wiiu\sdcafiine\00050000101BEB00\KoreanTranslation\content\data000.cpk`에 넣고, Aroma에서 SDCafiine을 켠 채 게임을 실행합니다.

자세한 방법은 동봉한 `README_한국어.txt`를 참고하세요.
