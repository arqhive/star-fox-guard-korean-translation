첫 공개 버전입니다. 게임 안의 일본어 텍스트 전체와 그림 속 일본어 2장을 한글화했습니다.

**원본 일본판 `data000.cpk`에 적용하는 전체 패치입니다.** 이미 한글 패치한 파일에는 적용할 수 없습니다.

## 변경 사항

- 게임 안의 일본어 텍스트 1,529문단을 모두 한글화했습니다(메뉴, 튜토리얼, 스토리 대사, 방해 통신, 도움말, 크레딧).
- 원본 UI 글꼴 모양에 맞춰 한글 글자를 새로 그리고, MCD별 글리프 아틀라스를 다시 만들었습니다.
- 그림 속 일본어 2장(프롤로그 계약서, 크레딧 손글씨 서명)을 한글화했습니다.
- 인물·지명은 한국 정식 발매작(스타폭스 2026, 스타폭스 64 3D) 표기를 따랐습니다.

## 배포 파일

| 파일 | 입력 | 설명 |
|---|---|---|
| `StarFoxGuard_KO_v0.9.zip` | 원본 일본판 `data000.cpk` | 스크립트 패처, `패치하기.bat`, 임베더블 파이썬, 사용자 설명서. |

패처는 시작할 때 원본 MD5를, 끝날 때 결과 MD5를 검사합니다.

## 적용 방법

1. `StarFoxGuard_KO_v0.9.zip`을 폴더째 풀고, 본인이 덤프해 복호화한 일본판 원본 `content/data000.cpk`를 `패치하기.bat`에 끌어다 놓습니다.
2. `out` 폴더에 만들어진 `data000.cpk`의 확인값을 아래 표와 비교합니다.
3. 결과 파일을 SD 카드의 `wiiu\sdcafiine\00050000101BEB00\KoreanTranslation\content\data000.cpk`에 넣고, Aroma에서 SDCafiine을 켠 채 게임을 실행합니다.

자세한 방법은 동봉한 `README_한국어.txt`를 참고하세요.
