# 문체·검수 규칙

## 기본
- 쉽고 자연스러운 한국어. 직역보다 뜻이 바로 통하는 표현을 쓴다.
- 인물·지명은 한국 정식 발매작 표기를 우선한다([`../translation/GLOSSARY.md`](../translation/GLOSSARY.md)).
- 원문의 말투를 유지한다. 반말 도움말은 반말로, 정중한 시스템 메시지는 해요/합니다체로.

## 마침표
원문(일본어)은 `。`를 전혀 쓰지 않지만, 한국어에는 넣는다.

- 완결된 문장(대사, 설명, 시스템 메시지)의 끝에 `.`를 찍는다. 한 문단에 문장이 여럿이면 각각 찍는다.
- 다음에는 찍지 않는다: 메뉴·버튼·탭 라벨, 화면 제목, 미션·로봇·칭호 이름, 명사구 캡션,
  점수·기록 항목, 이미 `!` `?` `...` `~`로 끝나는 줄, 감탄사만 있는 줄.
- 두 줄에 걸친 한 문장은 실제 문장이 끝나는 줄에만 찍는다.

## 쉼표
- 호격(이름을 부를 때)에는 쉼표를 넣는다. 예: `슬리피, 잘 들어.` / `수고했다, 신입 군.`
- 나열, 대조, 긴 종속절처럼 읽다가 쉬어야 하는 곳에 넣는다.
- 짧은 라벨이나 이미 읽기 쉬운 문장에는 넣지 않는다.

## 피해야 할 직역투
| 직역투 | 고친 표현 |
|---|---|
| ~하는 것이 가능하다 | ~할 수 있다 |
| ~라고 하는 | ~라는 / 빼기 |
| ~에 있어서, ~에 대해서 (남발) | ~에서, ~의, 빼기 |
| 명사+의 중첩 | 조사 정리, 문장 재구성 |
| 불필요한 피동 (~되어진다, ~받다) | 능동으로 |
| ~해 버렸다 | ~하고 말았다 / ~했다 |
| ~하지 않으면 안 된다 | ~해야 한다 |
| ~인 것이다 | ~이다 |
| 일본식 관용구 직역 | 뜻이 통하는 한국어 관용구 |

## 기술적 제약 (검사 도구가 자동으로 잡는다)
- `{btn:n}` 버튼 아이콘 태그는 개수와 종류를 그대로 유지한다. 그 밖의 `{` `}`는 쓸 수 없다.
- 줄 수는 원문 줄 수를 넘을 수 없다. 줄바꿈 위치는 자유롭게 바꿔도 된다.
- 줄 폭 한도: 원문 최장 줄이 250px 이상인 문단은 **원문 폭 그대로**(대사창·티커 칸이 원문 폭에 맞춰져 있어
  몇 px만 넘쳐도 화면에서 잘린다 — 실제로 HUD 티커에서 확인됨), 짧은 라벨은 버튼 여백을 감안해 10% 여유.
  한글 폭은 실제 글리프를 렌더해서 잰다(폰트별 평균값이 아니라 글자별 실측).
  글자는 가로로 6% 좁게 그린다(`font_build.XSCALE`). 문장을 더 줄이지 않고도 칸 대비 여유가 생긴다.
- 쓸 수 있는 문자: 한글, ASCII, `・…「」『』～♪★☆○×→←↑↓※△▽□◎●■▲▼◆◇`.
  일본어 가나·한자와 전각 문장부호는 쓸 수 없다.

```bash
python tools/tl_tool.py check all
```
